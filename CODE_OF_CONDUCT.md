# Community conduct

Treat contributors and users respectfully. Welcome different experience levels;
focus critique on code and reproducible evidence. Harassment, threats, doxxing,
discrimination and sharing private information are unacceptable. Maintainers may
remove abusive content or restrict participation, with a clear reason and a
proportionate response. Contact the repository maintainer through an appropriate
private GitHub channel for sensitive conduct reports; do not post private data
in public issues. This is an original short policy, not a claim of adopting an
unmodified external code-of-conduct text.
