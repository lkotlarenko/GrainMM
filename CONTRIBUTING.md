# Contributing

Read AGENTS.md, docs/CODE_QUALITY.md and the legal/platform/progress documents before editing.
Contribute original or clearly licensed code; document origin and retain notices.
Do not stage the local reference payload or private guiding documents. Keep
changes focused, update packaging/source-files.txt only after reviewing each new
path, and run source/package gates plus relevant host tests. Format new C++
using .clang-format. Record host/cross/physical evidence separately. Review [release readiness](docs/development/RELEASE_READINESS.md) and the
[automated release procedure](docs/development/RELEASING.md) before publication. Report reproducible issues with
versions and logs after reviewing them for private data. New code uses scoped GPLv3.
