# Target platform evidence

Primary target: Miyoo Mini Plus with OnionOS; not Mini v4/Flip/TrimUI.
No physical unit is connected or measured in this session. Family-level baseline:
SigmaStar SSD202D, dual Cortex-A7 ARMv7, roughly 1.2GHz, 128MiB RAM, 640x480.
Do not use those estimates as evidence about this user's firmware or stable clock.
