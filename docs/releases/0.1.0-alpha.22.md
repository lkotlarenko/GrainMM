# GrainMM0.1.0-alpha.22 — Brighter generative ambient instrument

Private development alpha; native publication is not authorized.

DRONE now offers more useful headroom, eight moods and a wider register. LEVEL
shows0–100%; an older saved maximum is20%, so raise it deliberately. Fresh defaults
stay silent. No device volume setting is changed. The source view shows four note
voices, level activity and melodic-event lights at the existing20Hz display cap.

For a first sound: Y then X selects built-in audio; keep OSC/LEVEL0 and BALLS/MODE
OFF. Open X → SOURCE → DRONE → A. Set LEVEL60%, ROOT60, MOOD MAJOR or LYDIAN, then
press A at low listening volume. EVOLVE SEC4 makes chord changes easier to hear.
Try REVERB/MIX0.25, lowering LEVEL if layered sounds or boosts clip.

R opens GENERATE: EVENT MIX adds sparse bright notes, EVENT RATE sets their pace,
GLIDE SEC softens chord changes, STEREO WIDTH narrows/spreads the source, SEED steers
future choices, and PATTERN chooses DRIFT/FORWARD/REVERSE/BOUNCE/HOLD. HOLD keeps the
chord while motion and events continue. Try EVENT MIX0.35/RATE0.70 as a starting point.

MENU saves and exits; reopening starts silent. Old1–14settings and patches load;
old pad patches retain their gains and start with event mix0. New126-control
settings15 and patches need alpha22+. WAVs and earlier saved files remain intact.
See [the measured baseline](../history/baselines/ALPHA22_BASELINE.md) for evidence and limits.
