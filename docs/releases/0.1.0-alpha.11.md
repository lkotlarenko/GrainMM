# GrainMM 0.1.0-alpha.11

## Musical grains and easier editing

- New HARMONY page: transpose, octave/fifth/major/minor/sus4 patterns, up/down/
  bounce/random order, octave ranges, chord chance and detune. Uses the existing
  sample buffer and16grain voices. Old settings start with harmony off.
- SELECT help now shows the selected control and keeps D-pad editing/L/R navigation
  available. X resets only that control. B/SELECT returns; A still plays/pauses.
- Help over sample/patch dialogs clearly returns to the dialog without editing sound.
- Settings9 saves72controls and preserves settings1–8. Earlier named patches still
  load; newly saved patches need alpha11 or later. Back up the whole state folder.

Load a tonal WAV, open HARMONY, choose MAJOR and play at low volume. Use lower
density for a sequence or higher density/longer grains for overlap. It does not
detect your sample's key or retune the oscillator. Large pitch shifts can alias.

Early alpha; no full GrainBrick parity or stable claim. Source and binaries remain
private at the owner's request. Future public GPL releases need matching source
and separate publication authorization. GrainMM by elly (@lkotlarenko), inspired by
GrainBrick by ETRNLIAM.
