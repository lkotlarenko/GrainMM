# GrainMM0.1.0-alpha.18 — Responsive studio and color profiles

Private alpha; not a stable release or full GrainBrick feature match.

- New instrument interface with waveform/scene, stereo meters, source activity,
  consistent controls and matching sample/patch/help/reset screens.
- X opens grouped SOURCE/FX/TEMPO/STYLE modules. A opens a module; B returns. Main A
  play/pause and MENU save/exit remain. L/R still changes pages.
- BALLS is a real collision instrument; BOWL edits note, scale and timbre. Physics
  and sound run on audio time; drawing uses bounded telemetry at up to20FPS.
- New settings12 preserve older files; newly saved patches require alpha17+.

[Install/update](../INSTALLATION.md) · [sound guide](../PARAMETERS.md).
Compare sources at low volume. Save/backup the whole state folder. Long stress,
headphones, power/sleep and all-on timing gates remain separate from short tests.

Owner-feedback fixes: sustained inward rebounds, paced20Hz animation/20ms input
polling, contiguous SOURCE/FX/TEMPO/STYLE ordering and six previewable/saved color
profiles. BURGUNDY is the readable default. STYLE saves separately in theme.v1;
B cancels previews. Sound settings stay12 and older musical files remain intact.

Matching burgundy/charcoal Onion launcher icon, generated from original vector-like
primitives with transparent rounded edges. The cached-surface copy avoids the
device SDL build’s per-blit diagnostic logging. Owner confirms substantially better
motion/responsiveness/navigation/themes; extended timing gates remain open.
