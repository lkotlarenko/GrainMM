# GrainMM 0.1.0-alpha.7

Save recovery fix for the Miyoo Mini Plus / OnionOS alpha.

If a saved WAV is missing, editing the synth or effects now keeps that WAV
selection. Restore the file at the same location and reopen to use it again.
Choosing a different source in the browser still replaces the selection normally.
Settings remain format v6; earlier files are preserved. Audio DSP is unchanged
from alpha6, whose synth, compressor, controls and saving were owner-verified.

Download **GrainMM-0.1.0-alpha.7-miyoo-mini-plus.zip**, rather than Source code.
Follow the [installation guide](../INSTALLATION.md); start at low listening volume.
For updates, back up the app folder and preserve its `state` folder.
See the [user guide](../../README.md) for sound sources and controls.

This is an early alpha, not full GrainBrick feature parity or a stable release.
