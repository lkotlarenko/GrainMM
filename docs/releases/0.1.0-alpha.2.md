# GrainMM 0.1.0-alpha.2

An early native granular instrument for **Miyoo Mini Plus with OnionOS**.
This is an experimental first release, with a small feature set.

## Install

1. Under **Assets**, download **GrainMM-0.1.0-alpha.2-miyoo-mini-plus.zip**.
   The **Source code** downloads are for developers and cannot be installed.
2. Back up existing GrainMM files and turn off your Miyoo. Open its SD card on
   your computer. Extract the ZIP onto the card: `App/GrainMM/config.json` should
   sit directly inside the card's `App` folder, without an extra enclosing folder.
3. Safely eject the card, put it back and start **Apps → GrainMM**.
4. Start with low listening volume. GrainMM opens silent; **A** plays/pauses,
   **MENU** exits. No firmware or system-library changes are needed.

For granular sounds, put your own short **16-bit PCM WAV** at
`App/GrainMM/state/sample.wav` and reopen the app. Without it, A plays a gentle
220Hz test tone. **↑/↓** select grain size, density, pitch, position, spread or
gain; **←/→** adjust. **X** switches to DELAY: time, feedback, mix,
ping-pong, stereo spread and feedback filtering. Increase MIX from zero to hear
echoes. A mutes the whole instrument, including delay tails. Edits save on normal MENU exit and restore next time.

## Updating and backups

Exit GrainMM and turn off the Miyoo before changing files. Copy the entire old
`App/GrainMM` folder somewhere safe on your computer. Move the old folder off
its original SD-card location, then extract the new ZIP. Copy only your old
`state` folder into the new installation. Do not restore old executables,
launchers, CURRENT selectors or releases folders into the new installation.
Keep the backup until you have tested the update.

## What to expect

Native ARMv7 C++ audio, 16 preallocated grain voices, bounded WAV loading, grain and delay
control pages, silent start, upright 640×480 software UI and app-local
state/logs. Includes the fix for Onion's audio-preload sample-path incompatibility.

Settings migrate by reading the older parameters.v1 and writing a separate
parameters.v2; the old file remains available for rollback.

Tested target: Miyoo Mini Plus, OnionOS 4.3.1-1. Other Miyoo models are untested.
This release does not include other GrainBrick effects, recording, a sample browser,
waveform editing, MIDI, or full project compatibility. Linear interpolation can
alias at higher pitches; sparse grains are intentionally quiet. Long-duration
listening, suspend/power behavior and VNC-disabled performance remain acceptance
work; host/ARM builds do not replace those tests. See the repository device report
for the precise physical checks completed before publication.
