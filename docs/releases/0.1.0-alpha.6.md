# GrainMM 0.1.0-alpha.6

Native sound instrument for **Miyoo Mini Plus with OnionOS**.

## New in this build

- A musical oscillator that works without a WAV and can layer with grains.
- Sine, triangle, saw and pulse waves; note, stereo detune, pulse width and vibrato.
- Stereo-linked compressor with threshold, ratio, attack, release, makeup and mix.
- Seven real control pages: GRAIN,DELAY,EQ,REVERB,MOTION,OSC,COMP.
- L/R move between pages; X also moves forward. Waveforms show names on screen.
- Settings v6 saves all42controls and the sound selection. Older settings stay intact.

The quiet220Hz test tone remains available at OSC/LEVEL0 when no WAV is loaded.
Raise LEVEL to use the musical oscillator. Its waveform edges reduce aliasing;
this is not a claim of perfect analog modeling. The compressor is not a brick-wall
limiter; excessive EQ/makeup/feedback can still clip. Start with low listening volume.

## Install

Download **GrainMM-0.1.0-alpha.6-miyoo-mini-plus.zip** under Assets, not Source code.
Turn off your Miyoo and extract the ZIP onto its SD card so `config.json` is at
`App/GrainMM/config.json`. Put the card back and open **Apps → GrainMM**.

Updating? Back up the old app folder, install a fresh folder and copy only the old
`state` folder into it. Keep the backup until tested. No firmware/system changes.

## Play without a sample

Press **Y**, then **X** to choose the built-in source. OSC opens automatically.
Set LEVEL to about0.05, then **A** to play. Choose WAVE or MIDI NOTE with↑/↓ and
change it with←/→. NOTE57 is A3/220Hz;69 is A4/440Hz. Add detune or vibrato gently.
Use **R** for COMP or **L** to move back. Raise effects MIX from0 to hear them.
**MENU** saves/exits; reopening starts paused. Controls work with either WAV +
oscillator or oscillator alone. GRAIN/MOTION require a WAV; the test tone bypasses FX.

For granular sounds, put short16-bit PCM WAVs in `App/GrainMM/state/`, press Y and
load with A. Loading starts silent. New oscillator/compressor controls default off,
so older sounds retain their settings. Original WAVs and v1–v5 settings are preserved.
