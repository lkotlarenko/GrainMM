# GrainMM 0.1.0-alpha.10

A larger instrument/workflow update for Miyoo Mini Plus / OnionOS.

## New

- 16 named patch slots save all 66 controls and source selection. Names use on-device
  D-pad editing. Replacing an occupied slot needs a second separate X press to confirm.
- Cached waveform display with live non-destructive trim/window controls.
- Transactional patch loads keep the old instrument on missing/invalid samples;
  successful loads start paused. WAVs are referenced, never copied or edited.
- CLI/application/view and codec/storage modules are separated for maintenance.
- Current GrainMM work switches to GPL-3.0-only. Earlier MIT grants and notices
  remain valid; original/third-party terms stay separate. Matching source archives
  and an explicit publication gate are prepared with release automation.
- Documentation is reorganized into current user/developer guidance and clearly
  marked historical evidence. Older measurements are preserved.

## Try it

At low listening volume, load a WAV. B opens the waveform; up/down selects a SAMPLE
control, left/right changes it, A plays/pauses, B returns. START opens patches and
pauses audio. X saves, A loads, Y edits the name for the next save, B/START closes.
Release X and press it again to confirm replacement. MENU saves normal settings/
exits; it does not save an unfinished patch-name draft.

Back up the entire state folder. Patches are state/patches/patch-01.gmm through
patch-16.gmm and refer to your WAV paths. Keep those WAVs when moving a patch.

## Distribution status

Early alpha. Native source and binaries remain private pending explicit owner
publication authorization. A future public GPL release must include its matching
source/build archive. This is not a public download or a stable/full GrainBrick port.
