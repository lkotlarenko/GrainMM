# GrainMM 0.1.0-alpha.8

## New

- TAPE adds saturation, tone, wow, flutter, mix and wet output level.
- Eight control pages with48saved controls; settings v7 preserves earlier files.
- Credits distinguish elly's original native implementation from ETRNLIAM's
  GrainBrick inspiration and the projects we learn from.

## Try it

Use a WAV or raise OSC/LEVEL for the built-in synthesizer. With low listening
volume, open TAPE using L/R. Start at MIX0.50, DRIVE6, OUTPUT−6, then try WOW0.5.
Set MIX0 to bypass. MENU saves and exits; reopening starts silent.

The effect is tape-style coloration, not an analog model. Partial mix also has a
short chorus-like phase character; high drive can alias or increase level.
The fallback test tone bypasses effects. Recording and MIDI are not included.

## Install

Download **GrainMM-0.1.0-alpha.8-miyoo-mini-plus.zip**, not Source code.
See [installation](../INSTALLATION.md) for SD-card steps and preserving `state`
when updating. No firmware or system modification is required.
