# GrainMM 0.1.0-alpha.9

A larger native instrument update for Miyoo Mini Plus / OnionOS.

## New in this build

- **RESONATE:** a tuned four-mode resonator with decay, brightness, inharmonicity,
  stereo width and wet/dry mix.
- **RHYTHM:** tempo-based tremolo and automatic stereo panning, note divisions,
  sine/triangle modulation and stereo phase.
- **SAMPLE:** non-destructive region start/end, adjustable grain window and stereo width.
- **SELECT help:** controls and a tip for the current page, while audio keeps playing.
- Eleven pages and 66 saved controls. Settings v8 preserves v1–v7 and missing-file recovery.

Sample-region/envelope edits affect new grains; sounding grains finish using their
previous region. ENV BLEND 0 is the familiar Hann window; raise it to hear ATTACK
and RELEASE. Original WAV files are never modified.

## Try it

Start at low listening volume with a WAV or OSC/LEVEL 0.05. For a pulse, choose
RHYTHM/TREMOLO 0.6 and TEMPO 120. Try AUTO PAN 0.5 with headphones. For tuned color,
raise RESONATE/MIX to 0.4 and match its MIDI NOTE to the oscillator, then vary
BRIGHTNESS or INHARMONIC. Use SAMPLE with a WAV to isolate a region and reshape
its grains. SELECT shows help; MENU saves/exits. Reopening always starts silent.

## Status and installation

Early alpha; longer sound/stress, headphone/power and VNC-off profiling remain.
The resonator is an original musical effect, not exact ORBIX/Rings behavior.
Recording, MIDI, named projects, shimmer and full parity are not included.

The owner currently publishes documentation only. Source and release automation
remain local; this version is not a public download. When authorized for release,
use **GrainMM-0.1.0-alpha.9-miyoo-mini-plus.zip** and the [installation guide](../INSTALLATION.md).
