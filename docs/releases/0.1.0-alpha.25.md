# GrainMM 0.1.0-alpha.25 — Patterns and WAV export

Private development alpha. Native publication remains unauthorized.

- Program a 16-step slice pattern with regions, rests, reverse and probability.
- Move region cut boundaries over the waveform without modifying the WAV.
- Switch between generated and manual patterns without losing manual edits.
- Keep patterns in settings, named patches and temporary sound snapshots.
- Export the complete instrument, shared effects and OUTPUT to a new stereo WAV.
- Choose 5, 15, 30 or 60 seconds; see progress and cancel an unfinished export.
- Find Export WAV, patches, master output and colors together in TOOLS.
- Open PATTERN directly from SOURCE; FX now contains only effects.
- Use the separate offline `grainmm-export` developer tool with saved settings.

Open SLICE and press B for the pattern editor. L/R selects a step, the D-pad edits,
X toggles a rest, Y switches pattern mode and A plays/pauses. Open TOOLS → EXPORT WAV for export; B on OUTPUT remains a shortcut. Export restarts the sound from its settings; live effect history is not
recorded. Playback remains paused afterward.

Settings migrate to schema 17 with an independent pattern section. Previous files
are preserved; new patches require alpha25 or later. The diagnostic granular
renderer is unchanged. This adds no live recording, MIDI or extra effects rack.

Exact host, sanitizer, ARM and physical status: [development handoff](../development/RESUME.md).
