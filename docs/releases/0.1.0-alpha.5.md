# GrainMM 0.1.0-alpha.5

Native granular synthesizer for **Miyoo Mini Plus with OnionOS**.

## New in this build

- A fifth MOTION page: reverse probability, random pitch, size and timing,
  stereo pan spread and scanning through the sample independently of pitch.
- Pitch variation up to±12semitones; forward/reverse grains can overlap.
- Each grain keeps its own launch settings. The fixed16voice pool stays bounded.
- Settings v5 stores all30controls and the selected WAV while preserving v1–v4.
- Retains the six-band EQ, stereo reverb, delay and WAV browser from alpha4.

X cycles GRAIN → DELAY → EQ → REVERB → MOTION. Start with PITCH RAND ST at3,
PAN SPREAD at0.5, or SCAN HZ at0.10. REVERSE CHANCE1 reverses every new grain;
0.5 gives a mixture. Motion starts at0 on older saved settings.

This remains an early port. Shimmer, ORBIX, tape, recording, MIDI, extra envelopes,
multiple grain layers and full project compatibility are still in development.
The goal is a useful native instrument with similar feature coverage and good
sound, rather than a bit-identical copy of GrainBrick.

## Install or update

Download **GrainMM-0.1.0-alpha.5-miyoo-mini-plus.zip** under Assets, not Source code.
Turn off the Miyoo and extract the ZIP onto its SD card so that the app is at
`App/GrainMM/config.json`. Put the card back and open **Apps → GrainMM**.

For an update, back up the old app folder on your computer, extract a fresh app
folder and copy only the old `state` folder into it. Keep the backup until tested.
No firmware update, system libraries or terminal commands are needed.

Start at low listening volume. **A** plays/pauses, **MENU** saves/exits. **Y** browses
WAV files from `App/GrainMM/state/`; loading starts paused. **↑/↓** select a control,
**←/→** change it, **X** changes pages. Raise reverb/delay MIX from0 to hear them.
Positive EQ boosts can clip; lower GRAIN/GAIN before large boosts. A mutes tails.

Tested target is Miyoo Mini Plus/OnionOS4.3.1-1. Host builds and silent tests do not
prove listening quality. Read docs/DEVICE_TEST.md for the exact physical acceptance
and remaining long-soak/headphone/power checks. This is an alpha, not full parity.
