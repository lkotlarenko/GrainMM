# GrainMM0.1.0-alpha.15 — Controls and reset choices

Private development candidate; no public download or stable claim.

Hold arrows to repeat; longer left/right holds accelerate scalar changes. Hold
START+SELECT for about a second, release, then choose a reset scope with up/down:
effects only, effects plus modulation, or all sound controls. X confirms, B cancels.
All-controls returns paused; selected WAV and stored patches remain untouched.
Effects pages show ACTIVE/BYPASS. Includes the alpha12 texture rack and alpha14 UI.

Install/update: [user guide](../INSTALLATION.md). Preserve the entire state folder.
Settings remain version10; earlier files stay intact. New patches require alpha12+.
