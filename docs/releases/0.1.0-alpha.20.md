# GrainMM 0.1.0-alpha.20 — Evolving grain drones

Private alpha; source/binary publication remains withheld.

Load a WAV, set SLICE/MODE OFF, then open X → SOURCE → DRONE → A. Choose WAVE,
DRIFT or BLEND and press A to play. RATE HZ controls the speed; POSITION DEPTH,
PITCH CENTS and SPREAD DEPTH shape the movement. Try pitch20/spread0.15 quietly.
SCAN HOLD holds movement while sound continues; MODE OFF removes drone offsets.

The saved grain base values stay intact. Existing grain envelope/harmony, filter
and reverb still shape the sound. This adds no sample copies or grain voices and
does not record live audio. It affects granular WAV playback, not slices or other
synth sources. Other random grain movement can remain during hold.

Settings13/114fields preserve old1–12files. Earlier patches load with drone mode
off; newly saved patches need alpha20+. The alpha19 SELECT-first A/B temporary
snapshot includes the new controls. MENU still saves/exits and reopening is silent.
Source/FX/Tempo/Style stay grouped; DRONE has cached waveform/base-position feedback.

See [sound controls](../PARAMETERS.md#sample-evolution) and
[development handoff](../development/RESUME.md) for actual verification/limitations.
Extended listening, headphones, power/sleep and timing-outlier profiling remain.
