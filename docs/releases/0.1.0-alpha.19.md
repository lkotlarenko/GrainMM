# GrainMM 0.1.0-alpha.19 — Temporary sound recall

Private alpha; publication remains withheld. This batch improves experimentation
on the accepted alpha18 studio/collision foundation.

- In the main control view, hold SELECT first, then tap A to capture a temporary
  sound or B to recall it. Release SELECT afterward. The banner confirms the action.
- Recall keeps playback running or paused as it was. No sample reload, SD snapshot
  file, extra audio voices or new sample buffer is involved.
- Loading a source invalidates the old snapshot; capture a new one to continue.
  Empty/invalid recall explains the problem and keeps the current sound.
- Capture replaces one temporary slot. It disappears on exit; use START patches
  for sounds you want to keep. Recall changes settings, not the running effect
  tails or clock/voice positions. Normal MENU save/exit still persists settings.
- Main A play/pause, B waveform, SELECT help, held reset and modal controls remain.
  Hold SELECT before A/B; the reverse button order keeps its ordinary behavior.

Sound settings stay12/108controls. All previous files/patches remain compatible.

[next-instrument report](../history/research/NEXT_INSTRUMENT_REPORT.md) for the planned
ambient performance/modulation, wavetable, pattern editor and export work.
