# GrainMM0.1.0-alpha.23 — Output control and ambient starting scenes

Private development alpha; source/binary publication remains unauthorized.

For more volume after effects: X → FX → OUTPUT → A. Turn LIMITER ON, then try
GAIN DB+6 at low listening volume. The activity bar shows limiting. If it stays
active often, lower gain. Balance/mono and limiter ceiling/release are also here.
Existing patches keep0dB; Onion/system volume is unchanged. This is sample-peak
limiting, not a guarantee against every possible reconstructed/intersample peak.

DRONE/GENERATE now have eight original starting scenes: press B, choose with ↑/↓,
change seed with ←/→, A applies and B/X cancels. Browsing keeps the current sound.
Applying keeps LEVEL, FX, other sources and playing/paused state. Raise DRONE LEVEL
if zero. Reverb/delay remain yours to steer; scenes do not silently add effects.

MENU saves/exits; reopening starts silent. Settings16/132controls preserve1–15files;
new patches need23+. Older patches load with neutral master output. Rack reset keeps
OUTPUT; all-sound reset returns it to0dB and pauses. No additional source voices or
sample copies; no system/library changes. See the measured alpha23 baseline.
