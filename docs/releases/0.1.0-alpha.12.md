# GrainMM 0.1.0-alpha.12

A larger effects and development-workflow update.

- CRUSH: bit depth, sample hold, drive, tone, mix and output.
- FILTER: low/high/bandpass, cutoff, resonance, drive, mix and output.
- CHORUS: rate, depth, delay, feedback, stereo width and mix.
- Hold SELECT+X together for1.5seconds to reset all processing effects and clear
  their tails. A short mute is intentional; prior play/pause returns. Source,
  oscillator, grain/trim/harmony settings and saved patches stay intact.
-15pages/90saved controls; settings10 preserves v1–v9 and older named patches.
- Shared typed parameter metadata reduces duplicated editor/codec work for the
  next sequencer/oscillator/layer/shimmer batches. See the detailed feature comparison.

At low listening volume, try CRUSH/BITS8,HOLD4,MIX0.3; FILTER/CUTOFF2000,MIX0.5;
CHORUS/MIX0.3. Each starts bypassed. The safe fallback test tone bypasses effects;
use a WAV or raise OSC/LEVEL. Back up state before replacing older patches.

Experimental development release; full GrainBrick parity and long stress/power/
headphone acceptance remain incomplete. Native source/binaries stay private pending
explicit publication authorization. GrainMM by elly (@lkotlarenko); original
GrainBrick by ETRNLIAM, PocketTracker acknowledged as research/inspiration.
