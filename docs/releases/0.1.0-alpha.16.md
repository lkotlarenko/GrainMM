# GrainMM0.1.0-alpha.16 — Slice sequences and consistent controls

Private alpha candidate, not a stable release or full GrainBrick feature match.

- MIX is always bottom-right on wet/dry effects; output/makeup sits beside it.
- New SLICE page plays16step generated sequences from your WAV, with forward,
  reverse, ping-pong/shuffle, region count, rhythmic division, gate, variations
  and reverse chance. Change shared TEMPO BPM on RHYTHM.
- Step/region indicators follow actual audio timing. MODE OFF returns to grains.
- Existing granular/oscillator/effects/patch controls remain; settings migrate
  into parameters.v11 while preserving older files. New patches require alpha16+.

Use low listening volume when comparing sources. [Install/update](../INSTALLATION.md)
and [sound controls](../PARAMETERS.md). Back up the whole state folder.
Manual step/cut editing, metronome, snapshot recall and collision visuals are future
work. New code GPL-3.0-only; earlier grants and third-party terms remain separate.

Native source/binaries remain local until publication is explicitly authorized.
