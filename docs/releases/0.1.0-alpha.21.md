# GrainMM 0.1.0-alpha.21 — Standalone generative drone

Private alpha; no public source/binary publication yet.

DRONE now makes ambient sound on its own, without a WAV. It has four sustained
stereo voices, automatic harmonic changes, breathing/pitch movement and quiet air
texture. Steer ROOT NOTE, MOOD, EVOLVE SEC, TEXTURE and MOVEMENT. LEVEL enables it;
A plays/pauses. The source uses the same filter/EQ/compressor/tape/delay/reverb rack.

For an isolated first sound, select the built-in source with Y then X; turn BALLS
MODE OFF if it was enabled. Open X → SOURCE → DRONE → A, raise LEVEL to0.10 and
press A at low listening volume. Set EVOLVE SEC4 to hear chord changes sooner.
Try MOOD MINOR/MAJOR/OPEN/DARK, then REVERB/MIX0.25. MENU saves/exits; reopen is silent.
Other enabled sources can layer with it; controls do not silently reset them.

The former sample DRONE page is named EVOLVE. It still moves WAV grains and keeps
its saved values. This correction follows the owner's clarification and MIASMORA
behavior reference; all new DSP is original, with no imported code/assets.
It is the first generative pad source, not the reference's full soundscape engine.

Settings14/120controls preserve1–13files. New patches need alpha21+; old patches
load with the new source disabled. Snapshot/icon are owner-confirmed. New source
listening/performance evidence is recorded in development/RESUME.md. All-FX timing,
long listening/headphones and power/sleep gates remain open.
