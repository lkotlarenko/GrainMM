# Security reports

This is an experimental local audio app, not a security-reviewed product. PCM16 sample import has explicit size/format/path limits and malformed-file tests;
it is not a general filesystem sandbox. Project import is not implemented. Do not submit secrets or personal
data in public logs. For sensitive vulnerabilities, use GitHub private vulnerability
reporting if enabled, or request a private maintainer contact without publishing
exploit details. No response-time guarantee is offered. Include affected commit,
platform, steps and impact. No root filesystem, firmware, networking or system
library changes should be necessary for a GrainMM proof run.
